# Proposal

## Why

The repository is documented in two languages. The decision of this session was that the README, docs, OpenSpec artifacts, comments, messages and manifests are in English, and everything written since then follows it (C7 and C8, three specs, the newer README sections). What was written before is still Spanish: most of the README, six of the nine main specs, the fixture manifest, the tools' docstrings, the comments, XML docs, exception and console messages of 17 source files and 32 test files, the build props, and the OpenSpec `config.yaml` that feeds the context of every future change. A reader (or a model reading the context) now meets both languages in the same file in some cases. This change finishes the job, with **no behaviour change**.

What I measured (lines with Spanish accents, files containing Spanish):

- `README.md`: 309 lines, 74 with accents; the Spanish sections are Plan, Estructura, Cómo validar, Texto y tokenizer, Vocoder de HeartCodec, Carga de pesos, Dónde te va a doler, Memoria and Licencia. The flow-matching and windowed-decode sections are already English.
- `tests/fixtures/MANIFEST.md` 113 lines / 37 (the C8 section is English), `tests/fixtures/README.md` 6 / 2.
- `tools/*.py`: `dump_reference.py` 21, `dump_text_reference.py` 15, `gen_python_text_data.py` 8, `decode_frames.py` 2.
- `src/HeartMuLa.Net`: 26 `.cs` files, 17 with Spanish, 110 lines (XML docs, comments, exception and console messages, the usage text of `Program.cs`).
- `tests/HeartMuLa.Net.Tests`: 51 files, 32 with Spanish, 153 lines (comments, assertion messages, `WriteLine` output, some Spanish test names).
- `Directory.Build.props` comments (3 lines), `openspec/config.yaml` (context and rules).
- Main specs in `openspec/specs`: `codec-vocoder` (89 lines, 19 with accents), `generation-loop` (63 / 18), `generation-reproducibility` (71 / 17), `model-parity` (58 / 14), `text-tokenization` (81 / 25), `weights-loading` (66 / 18). `audio-generation`, `codec-flow-matching` and `codec-windowed-decode` are already English.
- 14 test assertions match Spanish substrings of exception messages (`faltan`, `sobran`, `shapes distintas`, `índice 1`, ...), so those messages and their tests change together.

## What Changes

- Translate to English: the Spanish sections of the README, `MANIFEST.md`, `tests/fixtures/README.md`, the docstrings, comments and messages of the Python tools, all comments, XML docs, exception messages, console output and usage text in `src/` and `tests/`, the `Directory.Build.props` comments, `openspec/config.yaml`, and the six Spanish main specs.
- Rename the Spanish test methods to English (the list is recorded in the change; test IDs change, the set of tests does not).
- Update the 14 assertions that match Spanish message text together with the messages.
- List the user-visible CLI text that changes language in the README (usage, errors, progress lines such as `frames guardados en`).
- Add a small, throw-away verification script (kept in the change folder, not in the repository tree) that proves the C# edits touch only comments, string-literal text and the recorded renames.

**Not changed**: any logic, any identifier outside the recorded test renames, any fixture byte (including `text_cases.json`, `tokenizer_cases.json`, `prompt_ids.json`, whose Spanish and other-language content is test data and must stay as it is), the archived changes under `openspec/changes/archive` (they are history and stay as written), and the files generated by OpenSpec under `.claude/`.

**Not applicable**: numerical parity (no behaviour change). The acceptance criterion is instead behavioural identity: build with 0 warnings, the full CPU suite with the real checkpoint with the same counts as the last run (253 passed, 0 failed, 5 skipped, 258 total), every fixture file with the same sha256, and a mechanical check that the C# token streams are unchanged.

## Capabilities

### New Capabilities
None.

### Modified Capabilities
None. The six main specs are translated in place without changing any requirement or scenario (see the design for why this is not expressed as deltas); the change declares `skip_specs: true`.

## Impact

- Files: `README.md`, `tests/fixtures/MANIFEST.md`, `tests/fixtures/README.md`, `tools/*.py`, 17 files in `src/`, 32 files in `tests/`, `Directory.Build.props`, `openspec/config.yaml` and six files in `openspec/specs/`.
- Runtime: the language of exception messages, console output and the `generate`/`check` usage text changes. Nothing else.
- Tests: the same 258 tests; the renamed ones appear under new names in test reports.
- Cost: the full suite takes about 14 minutes on CPU; it runs once at the end, with a quick build and a selection of fast tests after each area.
