# Spec Delta

## Purpose

Defines that the C# forward pass of HeartMuLa (torchtune RoPE, backbone with KV cache and codebook decoder) reproduces the tensors of the Python golden run within fixed tolerances, and that this check runs as automatic tests and not by hand.

## ADDED Requirements

### Requirement: RoPE equivalent to torchtune's
The system SHALL apply the torchtune RoPE with Llama 3 scaling (rotation by adjacent pairs, `scale_factor` 32) and SHALL give the same result on successive calls with the same input.

#### Scenario: F32 at low and distant positions
- **WHEN** the RoPE is applied in F32 to the fixture input at positions 0..15 and at positions 4000..4015
- **THEN** the output differs from torchtune's by no more than 1e-4 in absolute value

#### Scenario: bf16
- **WHEN** the RoPE is applied in bf16 to the bf16 fixture input
- **THEN** each value differs from torchtune's by no more than 1 bf16 ulp

#### Scenario: Repeated calls
- **WHEN** the RoPE is applied several times in a row with the same input and positions
- **THEN** all outputs are identical to the first one

### Requirement: Backbone equivalent on the first frame
The system SHALL produce, for the reference prompt with CFG (batch 2), the final hidden state and the codebook 0 logits equivalent to those of Python.

#### Scenario: Reference prompt in bf16
- **WHEN** the backbone is evaluated on the fixture prompt with the HeartMuLa-oss-3B checkpoint in bf16
- **THEN** `last_h` and `c0_logits` have the fixture shape, `cos_sim` ≥ 0.999 and `max_abs` on the logits ≤ 0.5

### Requirement: Backbone equivalent throughout generation
The system SHALL maintain equivalence with Python during the 126 frames of the golden run when the tokens generated by Python are re-injected (teacher forcing), with the KV cache accumulating as in real generation.

#### Scenario: Logits per frame with teacher forcing
- **WHEN** the backbone is evaluated frame by frame re-injecting the Python frames, for the conditional and unconditional rows separately and before applying CFG
- **THEN** in each of the 126 calls `last_h` and the codebook 0 logits have `cos_sim` ≥ 0.999 and `max_abs` on the logits ≤ 0.5 with respect to the fixture

#### Scenario: No drift over time
- **WHEN** the last 26 calls are compared with the first 26
- **THEN** the worst `cos_sim` of the last ones is not lower than 0.999 and the `max_abs` tolerance is the same

### Requirement: Decoder equivalent on codebooks 1 to 7
The system SHALL produce the logits of codebooks 1 to 7 equivalent to those of Python when the decoder receives the hidden state of the backbone and the tokens of the previous codebooks from Python.

#### Scenario: Decoder logits with forced tokens
- **WHEN** the decoder is evaluated in bf16 with the `last_h` and the tokens from Python for the frames of the decoder fixture, for the conditional and unconditional rows
- **THEN** the logits of each codebook 1..7 have the fixture shape, `cos_sim` ≥ 0.999 and `max_abs` ≤ 0.5

### Requirement: Parity executable as tests
The parity check SHALL run with `dotnet test`, be explicitly skipped when there is no checkpoint, be able to run on CPU or CUDA, and fail without relaxing tolerances when any case does not comply.

#### Scenario: No checkpoint
- **WHEN** `HEARTMULA_CKPT` does not point to an existing directory
- **THEN** the tests that need it are skipped with an explicit reason and the rest of the suite passes

#### Scenario: Chosen device
- **WHEN** `HEARTMULA_DEVICE` is `cuda`
- **THEN** the same parity tests run on the GPU with the same tolerances
